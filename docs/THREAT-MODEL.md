# 威胁模型：SDK 匿名采集

## 风险接受记录
- 风险编号：SDK-ANON-WRITE-001
- 风险所有者：SDK 数据中台负责人
- 批准状态：临时接受
- 接受日期：2026-07-21
- 复审日期：2026-08-21
- 适用范围：`POST /api/v1/click`、`POST /api/v1/log`
- 退出条件：上线 app_id 签名鉴权、单 app 配额或等效服务端校验后，重新评估并关闭本记录

## 接受的风险
- SDK 接口为匿名采集模式，不验证客户端身份
- 任何客户端可传入任意字符串作为 app_id，服务端不校验其有效性
- 恶意写入可能导致数据污染和存储膨胀

## 已实施的缓解措施
1. 写入接口共享 IP 级速率限制（click + log 合计 10 次/秒/IP）
2. Nginx client_max_body_size 1MB
3. 写入失败时不返回假成功
4. 运维可通过 dashboard 发现异常写入模式

## 监控与处置阈值
1. 单 IP 写入持续超过 10 次/秒：应用层返回 429，Nginx 层按部署文档限流
2. 单 app_id 每小时写入量超过最近 7 日同小时均值 5 倍：人工复核数据污染风险
3. 数据库写入失败：接口返回 500 并记录 app_id，触发服务端错误告警
4. 存储增长超过容量预算：暂停异常来源、清理污染数据，并优先推进签名鉴权

## 待实施的增强（后续迭代）
